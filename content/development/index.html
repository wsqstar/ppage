如果你是第一次参与 PPage 开发，建议按以下顺序阅读：

  1. 先阅读项目根目录的 README.md 了解项目概况
  2. 查看 基础教程 了解如何使用 PPage
  3. 阅读本开发指南了解开发流程

🔧 开发环境

PPage 使用以下技术栈：

  • 前端框架: React 19 + Vite
  • 路由: React Router 7
  • Markdown 渲染: markdown-it
  • 配置解析: js-yaml
  • 代码质量: ESLint + Stylelint + Prettier

💡 贡献指南

欢迎提交 Issue 和 Pull Request！在提交 PR 之前，请确保：

  1. ✅ 代码通过 npm run lint 检查
  2. ✅ 代码格式符合 npm run format:check 要求
  3. ✅ 功能测试通过
  4. ✅ 提交信息清晰明确
